## Commands excluded or marked `verify`, and why

- **Left out:** factory reset (`restore factory-defaults`), `show running-config diff` or any configuration comparison, root guard, MSTP show and configure commands, `show system brief` and the Layer 3 `ipv6 nd` options. Their syntax was not confirmed in a page this pass.
- **MSTP:** the contents list for the MSTP chapter was cut off in the page that was read, so no MSTP command is on the sheet.
- **`verify` rows** (28): `show environment`, the `grep` filters, `show interfaces transceiver`, `show hardware counters interface`, `clear counters` with a port, `show mac-address-table address`, `mac-address-table static`, `show spanning-tree pvst vlan`, `ping ipv6`, `traceroute ipv6`, `router ospf` with `network`, `router bgp` with `neighbor`, `clear ip bgp` with an address, the ACL create, apply and remove rows, the two `copy running-config` backup forms, `management route`, `ip name-server`, the VLT domain row, the VRRP row, the port-mirroring row, DHCP relay, and the `mtu` row. Check each with `?` on the target switch.
- **`show ip management-route`** is in the S4048-ON 9.14.2.8 contents list under IPv4 Routing. A search result suggested it is OS10 only. The contents list is the better source, and the row is `index` level.

## Platform and release differences found

- OS9 interface names are `TenGigabitEthernet`, `fortyGigE`, `hundredGigE` and `ManagementEthernet`, written slot/port. Some platforms add a third part. OS10 writes `ethernet 1/1/1`.
- OS9 sets VLAN membership under `interface vlan N` with `tagged` and `untagged`. OS10 and Cisco IOS set it on the port (`switchport mode` and `switchport access vlan`).
- A plain OS9 switchport carries one untagged VLAN or several tagged VLANs. `portmode hybrid` allows both.
- OS9 spells the commands `show interfaces`, `show mac-address-table` and `show running-config`. OS10 uses `show interface`, `show mac address-table` and `show running-configuration`.
- OS9 port-channel membership is set on the member: `port-channel-protocol lacp`, then `port-channel N mode active` in the LACP sub-mode. OS10 uses `channel-group`.
- `default interface` needs 9.9 or newer. On 9.8 and older, use `no portmode hybrid` and `no switchport`.
- The MAC-clearing command takes different keywords on different platforms and releases.
- Port-channel limits differ: 128 on the S3048-ON and S4048-ON, 4096 on the Z9100-ON and S6000.
