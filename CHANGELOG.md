# Changelog

## Unreleased

- Rebrand. The product is now NetOps Workspace (NetOps for short), with the subtitle Offline tools for network engineering. Six tools have new visible names: Script Repository is Script Library, OSI & Network Reference is Network Reference, Config Diff is Config Compare, Ping / Traceroute Analyzer is Connectivity Analyzer, Network Topology Builder is Topology Builder, and Network Fault Lab is Switch Lab. Tool IDs, storage keys, source blocks, test file names and the GitHub repository name are unchanged, so saved settings, projects and lab progress carry over. Older entries below keep the names that were current when they were written.

- Visual refinement. One UI font (IBM Plex Sans) and one monospace font (IBM Plex Mono) are now embedded, Latin subset, woff2, four files, under the SIL Open Font License (docs/FONT-LICENSES.md). The kit still loads nothing from outside the file. Corner radii follow one scale: 16 px for cards and panels, 12 px for buttons, fields and tabs, 10 px for text areas and code, 8 px for small badges (buttons and tabs were full pills, cards 12 to 26 px). Panels, sidebars and bars lost their shadows; only menus, dialogs, toasts and drag keep one. The blue glow shadows in the vSphere Sandbox are gone. The home screen is denser with a smaller heading and a 44 px search field. The Log Sanitizer output heading lines up with the input heading. The Network Calculator menu no longer sits under the header on a phone. No command, simulation or feature changed. New tests: `tests/engine/uitokens.mjs` (contrast of the shared colours in both themes, the font files, no outside references) and `tests/browser/ui-design.test.mjs`.

- Cheat Sheet: a Dell OS9 sheet of 188 commands in 14 groups (system and health, interfaces, VLANs, MAC table, spanning tree, port-channels and LACP, LLDP, IPv4 and routing, IPv6, OSPF and BGP, ACLs and security, management, VLT and other features). It has its own pill, intro, topic chips and search hint, and it feeds Quick answers, All platforms search and hub search. OS9 and OS10 stay separate: VLAN membership is set under `interface vlan N`, interface names are `TenGigabitEthernet 1/1`, and `show interfaces` is plural. Rows carry a CLI mode and a `disrupts` flag where a command can drop traffic or cut off your session. Rows not confirmed for every release show `verify`. 70 rows were checked against a Dell page, 92 against the command index of the S4048-ON 9.14.2.8 guide, and 26 are marked `verify`. Sources and exclusions are in `docs/reviews/2026-11-03-os9-sources.md`. Nothing was run on a real switch. The Network Fault Lab still simulates OS10 only.
- Added Script Repository with the Free IP Finder (Invoke-LabScan) from the supplied older copy. It supports showing the code and copying it for PowerShell, and appears in hub search, the tool switcher and Help. Existing tool sources are retained from main.

- Deep review fixes (finding IDs from docs/reviews/2026-11-03-deep-review.md in brackets):
  - Log Sanitizer: the Wi-Fi key in `netsh wlan show profile key=clear` output (`Key Content : ...`) is now hidden (DR-11). A `name=` or `name:` value that is not a path is replaced with a plain `[ID_n]` token instead of a made-up log file path (DR-12).
  - Ping / Traceroute Analyzer: Windows `Packet needs to be fragmented but DF set.` and Linux `ping: local error: message too long, mtu=N` are read as probes that were too big for the path MTU, not as a target that may be down (DR-13, DR-14). So is a Linux `Frag needed and DF set (mtu = N)` reply from a router.
  - Switch Lab: `show inventory` names the same chassis as `show version` (DR-01). Labs 13 and 14 use Gi0/8, a port the WS-C2960CX-8TC-L has, as a routed port (DR-02, DR-06). Cisco `show spanning-tree` prints one PVST+ instance per VLAN with one root across the switches, leaves out shut, unconnected and routed ports, and `show spanning-tree summary` has its own layout (DR-03, DR-04, DR-07). An IP address on a Layer 2 port is refused (DR-05). `show vtp status` counts the VLANs `show vlan brief` lists (DR-08). A disabled or unconnected port shows auto speed and duplex (DR-09). Cisco Layer 3 switches take `ip routing` and `no ip routing` (DR-10). `spanning-tree vlan N root primary` and `root secondary` now change which switch is root in the guided lessons.
  - Review follow-up (IR-01 to IR-04): `spanning-tree vlan N root primary|secondary` now stores one priority per VLAN when the command runs, shows it in `show running-config`, keeps it across save and reload, and works on a list of VLANs (the incident lessons use the same rule). Spanning-tree instances exist for VLANs above 1005 as well. A Windows ping where a router answers `Packet needs to be fragmented but DF set.` no longer warns that the summary and the probes disagree, and says no echo reply came from the target. A profile name in quotes or with spaces (`name="My Home WiFi"`, `Name : My Home WiFi`, `netsh wlan show profile name=My Home WiFi key=clear`) is hidden whole. The earlier `name` rule rescanned runs of spaces and took 0.7 s on a 50,000-space line; it is now linear.
  - Log Sanitizer: the hostname rule no longer slows down on a long run of spaces or tabs. It took 1.5 s for 50,000 spaces and now takes 4 ms. It finds the same hostnames as before.
  - Tests: `tests/engine/switchlab.mjs` runs every guided lesson on both vendors, and the sanitizer and ping tests cover the new cases. CI runs them.
- Technical review fixes (the review's finding IDs in brackets):
  - Log Sanitizer: secrets in YAML block scalars (`password: |` followed by indented lines) are now hidden line by line (LS-01). A Digest `Authorization` or `Proxy-Authorization` header is hidden whole, in plain and JSON-quoted form (LS-02). Hostnames are found after `host=`, `server:` and similar fields whatever their ending, and under more suffixes in plain text (LS-03). The default allow-list no longer contains mask-looking numbers: a subnet or wildcard mask is kept where it is a mask, and the same number as an address is hidden (LS-04). Deleting a mapped entry no longer renumbers later placeholders, so an old reply can never restore a different value (LS-05). The README, architecture guide and the Download Text button now say that the sanitized text is plain text and only saved state is encrypted (LS-06).
  - Config Diff: a large or very different comparison keeps the order of lines instead of matching by content, so a reordered ACL is never reported as unchanged (CD-01). Ignore whitespace leaves spaces inside quotes alone (CD-02).
  - Network Calculator: the extended ACL example is split into an allow-everything list and a services-only list, and the iptables and nftables lines come from the same service table, including UDP 53, with the drop-policy prerequisite stated (NC-01, NC-02).
  - Network Fault Lab: spanning-tree election uses link speed for path cost, shown with the same numbers `show spanning-tree` prints, and compares port numbers as numbers (SW-01, SW-02). Cisco `root secondary` sets 28672 (SW-03). A rejected `spanning-tree vlan N priority` leaves the switch untouched (SW-04). The advanced commands now go through the normal console path, so configuration-mode, `do`, abbreviation, pipe and history rules apply (SW-05). Untagged frames on a trunk are dropped when the native VLAN is not in the allowed list (SW-06). ACL lines are checked for valid addresses and for qualifiers the lab does not simulate (SW-07). The access list lesson is fixed by correcting the rule and keeping the list bound (SW-08).
  - Routing Lab: a route with administrative distance 255 is refused and never used (RT-01). A note explains installed routes versus the forwarding lookup (RT-02).
  - DNS Lab: an `ANY` query returns the alias record and does not chase it (DNS-01). An SRV target of `.` is accepted (DNS-02). A note explains that `.local` is a simplification (DNS-03).
  - vSphere Sandbox: the memory model is stated as fully reserved (VS-01). Adding CPU or memory to a running VM needs hot add turned on while it is powered off (VS-02). Deleting a VM returns its snapshot space (VS-03). Reboot host walks through Not Responding and back, and needs Maintenance Mode (VS-04). Restart Guest OS needs VMware Tools, like Shut Down Guest OS (VS-05).
  - Topology Builder: a netmask that is not contiguous no longer becomes a prefix length (TP-01).
  - Cheat Sheet and reference: Junos `commit check` is described as confirming a pending `commit confirmed` (CS-01). The IPv6 entry separates neighbor discovery from address configuration (OR-01).
  - Ping / Traceroute Analyzer: probe results are no longer described as what real traffic sees (PA-01), loss is placed with a size check and called a suspect area (PA-02), and negative or damaged mtr numbers are rejected (PA-03).
- Network Fault Lab: switches start in user EXEC mode, so `enable` comes before `configure terminal`, and `?` lists only the commands for the current mode. Dell switches take Dell port names (`interface ethernet 1/1/1`), and the PCs answer `ping` in the Linux format.
- Network Fault Lab: when a ticket's goal is met, run the test shown under the goal, then press Verify your repair to reach the quiz.
- Main menu: each card has a pin button after its title. Left and Right visit the title, the pin, then the next card.
- Network Topology Builder: everything saved with network details is encrypted and asks for a passphrase first, including the project file, the CSV lists and the health report. The PNG and SVG pictures are not encrypted.
- Main menu: the arrow keys now follow the layout. Down and Up move between rows in the same column, Left and Right move along the row, and Up from the top row goes back to the search box. Before, Down and Right both stepped to the next card in list order, so Down jumped sideways first.
- Network Fault Lab: Dell is now the default vendor for new visitors (anyone who already chose one keeps it).
- Network Fault Lab: `?` now works like a real switch. It lists the commands for the current mode (EXEC, configuration, interface, access list) in alphabetical order with a short description, and `show ?` and `do show ?` list what can follow. The list follows the chosen vendor: Cisco shows `show interfaces`, `cdp` and `etherchannel`, Dell shows `show interface` and `port-channel`. `help` still prints the full guide.
- Network Fault Lab: `show interfaces` now prints each vendor's own format. Cisco uses the full interface name and the state word (`GigabitEthernet0/1 is up, line protocol is up (connected)`) and the IOS body, with no invented switchport section. Dell prints the OS10 layout, and `show interface status` has the OS10 columns (Port, Description, Status, Speed, Duplex, Mode, Vlan, Tagged-Vlans). On Dell, `show interfaces` (with an s) still works but says OS10 spells it `show interface`.
- Network Fault Lab: fixed `show interfaces trunk`, `show interfaces switchport` and `show interfaces status err-disabled`, which printed a full dump of every port instead of their own output.
- Network Fault Lab: a Free practice card at the end of the lab list opens a working office network (two access switches and a Layer 3 switch) with no fault, goal, hints or quiz. Reset Lab restores it, and it never changes lab progress.
- Network Calculator: a new IPv6 Calc tab with a subnet calculator (compressed and expanded forms, network and range, address type and scope, interface ID and EUI-64 detection, solicited-node and reverse DNS names), a prefix splitter (for example a /48 into /64s, with a jump-to-number field) and a MAC to EUI-64 builder. The IPv4 Subnet Calc hands an IPv6 address over to it.
- Ping / Traceroute Analyzer: reads `mtr` reports, WinMTR, `pathping`, PowerShell `Test-NetConnection` (with `-Port` and `-TraceRoute`) and `Test-Connection` (PowerShell 5.1 and 7), with plain-English notes on where loss really starts and what is only a router rate-limiting its replies. A "More examples" menu has a sample of each.
- Network Topology Builder: Export now has a draw.io file (`.drawio`), with zones, device shapes, link styles and interface names, and the device details kept as draw.io data. Device configurations are never written to it.
- Network Topology Builder: reads Windows servers and PCs. `ipconfig /all`, `Get-NetAdapter` (table or list), `Get-NetIPConfiguration`, `Get-NetIPAddress`, `Get-NetLbfoTeam`, `Get-NetLbfoTeamMember` and `netsh interface show interface` can be pasted in any order, with or without a PowerShell or command prompt in front of each. NIC teams become port-channels, and a team that shares a MAC with its first NIC does not take the switch port away from that NIC. Output that names no host (a team, netsh) goes to the host whose `ipconfig /all` came in the same input. Windows prints no neighbour discovery, so the cables come from the switch side, matched to the NICs by MAC and drawn as inferred. Hyper-V, VPN, Bluetooth, Wi-Fi and tunnel adapters are listed but never cabled, and a self-assigned 169.254 address is explained. English output only. The import dialog now lists Linux servers too, which were already read. An output that names a host now reaches a device first recorded under only a MAC or IP, instead of being held as ambiguous.
- Tests: the engine tests (71) and the browser tests are in the repository under `tests/` and run in CI.

## 1.0.0 (2026-10-17)

First tagged release.

- Twelve tools in one offline file: seven work tools (Log Sanitizer, OSI & Network Reference, Network Calculator, Cheat Sheet, Config Diff, Ping / Traceroute Analyzer, Network Topology Builder) and five practice labs (DNS, Routing, Firewall Rules, Network Fault, vSphere Sandbox).
- Network Topology Builder opens with a sample network so there is something to explore on first load.
- `scripts/check-scripts.mjs` syntax-checks every script in `index.html`, including the embedded tools. It runs on every push.
